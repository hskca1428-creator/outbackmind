# Placeholder icons

These icons are generated stand-ins (sun over red-earth hills in the outback palette),
not an approved logo. To swap in a real logo: replace `icons-src/icon.svg` and `icons-src/favicon.svg`
(or overwrite the PNGs here: 192, 512, maskable-512 with the logo inside the central 80%, apple-touch 180, favicon.ico)
then run `python3 scripts/build_offline_pack.py` so the service worker picks up the new files.
